# Contribution status

FreeDNS Updater is retired and being archived. New features, provider integrations
and ongoing runtime fixes are not planned. Historical modernization proposals
should be treated as discontinued work, not delivered functionality.

For new installations, see the independent
[qdm12/ddns-updater](https://github.com/qdm12/ddns-updater) project and its own
contribution/support guidelines. Report replacement-specific issues there.

Final corrections to this repository should concern the accuracy of its historical
source or retirement documentation. Keep credentials, deployment inventories and
unredacted runtime logs out of public issues, pull requests and commits.

See [retirement notes](docs/retirement.md). The existing [license](LICENSE) remains
unchanged.
